# QuizMaster

QuizMaster — це вебзастосунок для створення, проходження та редагування вікторин.

## 🎯 Мета проєкту

Користувачі можуть реєструватися, створювати власні тести для дітей і дорослих, проходити вікторини інших користувачів, перевіряти результати, залишати відгуки, оцінювати тести та додавати їх до обраного. Також застосунок передбачає особистий профіль, статистику проходжень і пошук тестів за категоріями та рейтингом.

## 🛠 Tech Stack

### Frontend
- React 18 + Vite — швидка збірка та HMR
- Tailwind CSS — utility-first стилізація з кастомними breakpoints (320px / 768px / 1440px)
- React Router DOM — клієнтська маршрутизація
- Axios — HTTP-клієнт

### Backend
- Node.js + Express — REST API сервер
- PostgreSQL (Neon) + Prisma — serverless база даних та ORM
- JWT — аутентифікація
- Jest + Supertest — тестування
