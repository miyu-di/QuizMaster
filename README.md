# QuizMaster

QuizMaster — це вебзастосунок для створення, проходження та редагування вікторин.

## 🎯 Мета проєкту

Користувачі можуть реєструватися, створювати власні тести для дітей і дорослих, проходити вікторини інших користувачів, перевіряти результати, залишати відгуки, оцінювати тести та додавати їх до обраного. Також застосунок передбачає особистий профіль з аватаром, статистику проходжень і пошук тестів за категоріями та рейтингом.

## 🛠 Tech Stack

### Frontend
- React 18 + Vite — швидка збірка та HMR
- Redux Toolkit — керування глобальним станом застосунку
- React Router — клієнтська маршрутизація (SPA)
- CSS — стилі, ізольовані по компонентах; глобальні змінні в `:root` (кольори, шрифти) і `@font-face`; кастомні брейкпоінти: до 375px (fluid), 375px (mobile), 768px (tablet), 1440px (desktop)
- Axios — HTTP-клієнт (окремий інстанс із базовим URL і `withCredentials: true`)
- Swiper — слайдери для `BaseQuizList` (планшет і мобільний) та `Reviews`
- ESLint + Prettier — єдиний стиль коду

### Backend
- Node.js + Express — REST API сервер
- MongoDB (Atlas) + Mongoose — документна база даних та ODM (сутності `User`, `Quiz`, `Question`, `Review`)
- JWT у httpOnly cookie + bcrypt — автентифікація та хешування паролів
- Joi — валідація вхідних даних на сервері
- Swagger UI (`swagger-ui-express`) — інтерактивна документація API за маршрутом `/api-docs`
- Jest + Supertest — тестування (покриття ≥ 70%)

### Інфраструктура
- MongoDB Atlas — хмарна база даних
- Vercel / Netlify — хостинг frontend
- Render / Railway — хостинг backend
- Cloudinary — хмарне сховище для аватарів користувачів

> Детальне обґрунтування вибору технологій — у файлі [TECH.md](./TECH.md).
